# 1.4.0 发布说明

状态：测试版。编译、单元测试、Lint 和 APK 签名检查已通过；真机验收待完成。

- 常驻显示当前 BLE 设备名称和地址，增加可折叠连接信息：GATT 状态、配对状态、设备类型、ATT MTU、PHY TX/RX、RSSI。
- 连接后串行读取一次 RSSI/PHY；暂停时可刷新信息、手动协商 MTU，测量中不轮询诊断参数。
- BLE CSV 增加连接参数快照、来源和观测时间，每条采样用 ble_connection_info_id 关联当时参数，保留完整 payload；USB 六列格式不变。
- OTA 按 DNS、超时、TLS、HTTP 分类显示中文错误，失败时提供官方发布页入口，保留 APK 摘要、版本和签名校验。
- “管理配对”打开系统蓝牙设置，由用户取消配对。

ATT MTU 不等于 LL 包长。当前 SDK 35 公开接口无法取得 LL 长度、连接间隔、peripheral latency、supervision timeout；这些数值留空并标记不可获取，不从通知频率推算。未收到 MTU 回调时显示未上报。DNS 错误提示与备用入口不改变手机网络配置，无法保证受限网络可访问 GitHub。详细设计与排查思路见 [蓝牙连接信息与 CSV](../ble-connection-info.md)。

版本为 1.4.0 / versionCode 5，最低 Android 8.0 / API 26，targetSdk 35。已执行 assembleDebug、testDebugUnitTest、lintDebug：35 项单元测试全部通过，Lint 0 错误、4 条警告（备份规则建议、重复背景绘制、两处文字拼接）。BLE、USB、悬浮窗、配对管理与 OTA 尚未真机验收。

发布附件：GamepadRate-1.4.0-debug.apk、SHA-256、源码 ZIP 和构建信息。本包沿用 1.3.0 调试签名，证书 SHA-256 为 719026cd16a38990106bac1ee39fcf590a010771053368d5efbe100b634ed69c，可覆盖同签名旧版。1.3.0 检查更新若因 DNS 失败，请通过发布页手动下载安装；安装仍由 Android 系统确认。
