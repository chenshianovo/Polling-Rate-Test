# 1.3.0 发布说明

状态：测试版。编译、单元测试、Lint 和 APK 签名检查已通过；真机验收待完成。

- 底部固定 BLE、USB、我的，默认 BLE；设置与标准手柄入口统一到“我的”。
- 精简常驻操作说明，圆角按钮和主操作高亮，保留白天/黑夜/跟随系统。
- 灰色半透明悬浮窗，点击展开开始/继续、暂停、导出、关闭；拖动只移动窗口。
- BLE 订阅或 USB 通道就绪后自动开窗开始，暂停续录不混入跨暂停间隔。
- 自选导出目录、持久授权与完整 payload CSV；导出使用暂停时的独立快照。
- 应用内检查 GitHub Release，验证 APK 后由 Android 系统确认安装。

版本为 1.3.0 / versionCode 4，最低 Android 8.0 / API 26，targetSdk 35。已执行 `assembleDebug testDebugUnitTest lintDebug`：30 项单元测试全部通过，Lint 0 错误、4 条警告（备份规则建议、重复背景绘制、两处中文文字拼接）。使用 AndroidX Core 1.15.0 提供 FileProvider。USB、BLE、悬浮窗交互和 OTA 尚未真机验收。

发布附件：`GamepadRate-1.3.0-debug.apk`、SHA-256、源码 ZIP 和构建信息。此包使用与 1.2.0 相同的调试签名，证书 SHA-256 为 `719026cd16a38990106bac1ee39fcf590a010771053368d5efbe100b634ed69c`。自行构建时必须保留相同签名才能覆盖安装。

OTA 读取 GitHub 附件 digest；摘要缺失、签名不同或 versionCode 未增加时拒绝安装。旧版 1.2.0 需要先手动安装本版，才能使用后续 OTA。下载校验通过后仍需用户在系统安装界面确认。
