# v1.2.0 — USB、完整 payload、主题与透明悬浮

新增 USB/OTG Interrupt IN 接收测试；BLE/USB CSV 现包含每次接收的完整 `payload_hex`，方便对照按下、松开和协议数据。所有测试卡片支持折叠，主题支持白天、黑夜与跟随系统。BLE/USB 增加透明、可拖动悬浮窗及前台服务，允许切换应用后继续采集。

使用：连接设备并选择通道 → 允许悬浮权限（如需要） → 开启悬浮窗 → 开始测试。点 ×、锁屏或移除任务会停止测试；系统杀进程会丢失未导出的内存数据。

## 安装与测量范围

- Android 8.0+；下载 APK 后直接安装，使用与先前 1.0/1.1 相同的调试证书。
- 此为调试签名测试包。USB/BLE/悬浮窗尚未经过实际手机与手柄验证。
- USB 需 OTG/Host，支持默认配置 Alt 0 单事务 Interrupt IN。接管接口可能影响游戏使用该手柄，结束后应释放接口，必要时重新插拔。
- 完整 payload 指本次回调/接收的全部字节，USB 跨包报告不会自动重组；标准输入模式无法取得原始 payload 或跨应用后台采集。
- Hz 是应用侧接收率，不是空口发包率、硬件扫描率、USB 总线全部轮询次数或按键延迟。
